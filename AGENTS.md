# Medium automation test instructions

This repository is a small, self-contained test fixture for draft/import
formatting. `post.md` is the source fixture. `post.html` is generated output
and remains ignored unless a future task explicitly promotes it.

- Drafting, rendering, and local inspection are allowed.
- Never publish, import, schedule, submit, or otherwise create a Medium post
  without the user's explicit approval for that exact action.
- Do not add credentials, account details, browser profiles, or local paths.
- Keep new fixtures generic and value-free. Review the tracked diff before a
  commit or push; neither is implied by fixture work.
